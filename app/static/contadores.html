Consulta masiva (Contadores)

Sube un archivo .xlsx con una fila por cliente y el sistema procesa todos secuencialmente.

Guía rápida
  • Formato .xlsx (primera hoja, primera fila = encabezados).
  • Columnas requeridas: tipo_documento, numero_documento y contrasena.
  • fecha_vencimiento y estado: las alimenta el sistema al terminar cada cliente.
  • Re-ejecución: las filas con estado = ok ya procesadas se saltan.
